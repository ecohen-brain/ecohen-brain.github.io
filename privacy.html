Privacy policy

Last updated: November 10, 2026

Brain is a private tool used only by its owner, with the owner's own Google accounts.

What it accesses

With the owner's permission, Brain reads and manages the owner's Gmail, Google Calendar, Google Drive, Docs, Sheets, Slides and Contacts, so it can summarize email, add calendar events and prepare draft replies.

How data is used and stored

  • Data is used only to help the owner with their own tasks.
  • Access tokens and any working copies are stored only on the owner's own computer.
  • Data is not sold, shared with third parties, or used for advertising.
  • Brain's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
